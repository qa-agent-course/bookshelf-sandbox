# BS-106 Promo codes
- Type: Story
- Status: Ready for test
- Priority: Medium
- Reporter: Product Owner (fictional)
## Description
As a reader I want to use promo codes from newsletters.
## Acceptance criteria
1. A reader can apply one promo code per order.
2. `WELCOME10` gives 10% off the subtotal.
3. `BOOKS5` gives 5.00 EUR off when the subtotal is 25.00 EUR or more.
4. `WELCOME10` can be combined with any other promo code.
5. Free delivery is calculated from the subtotal before the discount.
## Notes
Marketing wants the free-delivery message to "always match the total the reader pays".
